Camera Calibration - Script allows user to click multiple images of the checker board and obtain the intrinsic matrix and distortion coefficients. 
Checkerboard Distance - Script begins shooting a video, stand with a checkerboard and move it around. It shall estimate the distance and other params (Roll, Pitch Yaw). 
Checkerboard_3d_animation and checkerboard_motion_analysis - Helper files that perform analysis and save the plots. 
Instructions to Run - Print out the checkerboard, calibrate it first (20-25 photos). Then run the checkerboard distance file (either from Terminal, or your IDE of choice)
